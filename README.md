# 영상 전체화면 도우미 0.1.1

Windows용 Obsidian 1.15.0에서 웹뷰어와 Canvas 링크 영상의 기존 전체화면 버튼을 사용합니다. 같은 플레이어를 확대하므로 재생 위치가 이어집니다. 전체화면 버튼을 다시 누르거나 Esc를 누르면 원래 화면으로 돌아갑니다.

## 설치

1. ZIP을 풀고 video-fullscreen-helper 폴더를 원하는 보관함의 .obsidian/plugins 폴더 안에 복사합니다.
2. Obsidian에서 설정 → 커뮤니티 플러그인을 열어 목록을 새로고침한 후 ‘영상 전체화면 도우미’를 켭니다.
3. 웹뷰어에서 영상을 열거나 Canvas에 영상 링크를 붙여 넣고 재생한 후 플레이어의 ⛶ 버튼을 누릅니다.

## 적용 범위

유튜브 웹페이지와 Canvas 링크 플레이어의 기존 버튼, 웹 플레이어가 자바스크립트로 보내는 표준 전체화면 요청을 처리합니다. 외부 사이트의 자체 플레이어와 브라우저 내장 컨트롤은 동작이 다를 수 있습니다. 플러그인이 직접 소리 설정을 바꾸지는 않습니다.

## 검증한 환경

Windows, Obsidian 1.15.0, 1920×1080 화면에서 유튜브 웹뷰어·Canvas 링크 영상과 표준 전체화면 API를 호출하는 HTML 영상으로 확인했습니다. 전체화면 진입과 복귀, 분리 창의 전환, 전체화면 중 플러그인 비활성화와 탭 닫기를 시험했습니다.

main.js가 실행 코드이자 편집 가능한 소스입니다. 소스 변경 후 node --check main.js로 구문을 확인할 수 있습니다.
